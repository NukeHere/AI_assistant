# Уведомления AI Assistant

Клиенты показывают локальное уведомление, когда серверная временная память создаёт системное событие напоминания.

## Что уже работает

- Desktop: popup-окно поверх остальных окон и звуковой сигнал `bell`.
- Android: системное notification в канале `AI Assistant reminders`.
- Одинаковое напоминание не спамится повторно: каждый клиент хранит локальный список уже показанных `message_id`.
- Уведомление приходит через обычную синхронизацию истории, поэтому отдельный серверный endpoint не нужен.

## Важное ограничение MVP

Уведомления сейчас надёжно работают, когда клиент запущен и периодически синхронизируется. Для настоящего режима “пришло даже если приложение закрыто” нужны отдельные фоновые компоненты:

- Android: `WorkManager` или foreground service.
- Windows: tray/background agent или отдельный сервис.

Это следующий слой, когда MVP уведомлений будет проверен руками.
