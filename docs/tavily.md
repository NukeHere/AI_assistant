# Поиск Tavily

В Environment сервиса Render добавьте `TAVILY_API_KEY` и сохраните с применением к новому деплою. Локально ключ можно задать в игнорируемом `.env`, если запускатель загружает его в окружение процесса. Не добавляйте ключ в Git.

Сервер сообщает модели доступность поиска. Приватный блок `assistant_memory` поддерживает `{"web_search":{"query":"запрос"}}`. Используется Search API: basic, до трёх результатов, один запрос на ответ, таймаут 20 секунд. Данные выдачи ограничены по размеру. Модель получает ссылки и выдержки и формирует ответ по-русски. Поиск расходует квоту Tavily.

После поискового ответа дополнительные команды модели (память, таймеры, Telegram-действия) не выполняются: недоверенная выдача не должна вызывать побочные действия. Ошибки возвращаются модели без секретов. Аудит `web_search` содержит статус и число источников.
